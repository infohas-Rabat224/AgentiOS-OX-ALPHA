================================================================================
                    AgenticOS Portable Desktop Edition (v1.0.0-rc10)
                 Autonomous Multi-Agent Operating System Runtime
================================================================================

HOW TO RUN:
1. Double-click "AgenticOS.exe" to launch the native desktop application.
2. The application will automatically:
   - Initialize the local hardware-bound Credential Vault
   - Boot the native AgenticOS Kernel Daemon on http://127.0.0.1:8001
   - Mount the Mission Control UI on http://127.0.0.1:3000
   - Launch the dedicated desktop UI window in Edge App Mode or default browser
3. No Python or Node.js installation is required for normal operation.

DIRECTORIES:
- dist/             : Pre-compiled production React/TypeScript interface
- AgenticosHybrid/  : Kernel v2 and Python agent orchestration modules
- logs/             : Application and kernel diagnostic traces

Documentation: https://github.com/infohas-Rabat224/AgentiOS-OX-ALPHA
